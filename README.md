# MATLAB-Lab-Assignments

Digital Image Processing lab assignments and experiments implemented using MATLAB.

## Files

| File | Description |
|------|-------------|
| `Tambola_ticket_generator.m` | Generates a valid randomized Tambola ticket and displays the generated ticket as output. |
| `random_array.m` | Generates a random array and displays the generated array as output. |
| `rgb_colour_differentiation.m` | Separates an RGB image into Red, Green, and Blue channels and displays the individual colour components. |
| `rgb_differentiator_clustering.m` | Performs RGB colour differentiation using clustering and displays the resulting segmented image. |
| `Bit_plane_slicing.m` | Extracts the individual bit planes of a grayscale image and displays the bit-plane slicing results in a grid. |
| `histogram_equalization.m` | Performs histogram equalization on an image and displays the original image, equalized image, and their histograms for comparison. |
| `types_of_HE.m` | Demonstrates different types of histogram equalization and displays the processed images and corresponding histograms. |
| `Discrete_wavelet_transform.m` | Performs Discrete Wavelet Transform (DWT) on an image and displays the wavelet decomposition and reconstructed output. |
| `edge_detection_code.m` | Performs edge detection on an image and displays the detected edges using different edge detection methods. |
| `huffman_coding.m` | Performs Huffman coding for image compression and displays the coding results, code lengths, and compression-related output. |
| `shannon_fano_coding.m` | Performs Shannon-Fano coding for image compression and displays the generated codes, code lengths, and compression-related output. |
