# MATLAB-Lab-Assignments

Digital Image Processing lab assignments and experiments implemented using MATLAB.

## Files

| File | Description |
|------|-------------|
| `Tambola_ticket_generator.m` | Generates a randomized Tambola ticket. |
| `random_array.m` | Generates and displays a random array. |
| `rgb_colour_differentiation.m` | Separates and displays the RGB colour channels of an image. |
| `rgb_differentiator_clustering.m` | Performs RGB colour differentiation using clustering. |
| `tambola_ticket_output.png` | Output image generated by the Tambola ticket program. |

## Tools Used

- MATLAB
- Digital Image Processing

## Topics Covered

- RGB Colour Processing
- Image Differentiation
- Random Array Generation
- Tambola Ticket Generation
